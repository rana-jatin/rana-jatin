## 🚀 Featured Projects

### MindMitra
**Live:** https://mindmitra.co.in
**Stack:** Python · React · TypeScript · PostgreSQL · Redis · Supabase · Vercel · Linux

- Context-aware multi-agent LLM router across five providers with fallback/retry.
- Human-in-the-loop guardrail layer: real-time risk classification plus expert escalation.
- Async REST services over PostgreSQL + Redis with queue-backed background workflows.
- Structured logging and accuracy benchmarking on labelled live traffic.

### raeth — deterministic CLOB matching engine (Rust)
**Repo:** https://github.com/rana-jatin/raeth-matching-engine

- 14.38M ops/s, ~400 ns p99.
- Strict price-time priority; never crosses the book; exact share conservation; bit-for-bit deterministic replay.
- Property-tested over hundreds of randomized command streams.
- Zero heap allocation on the steady-state hot path; no `unsafe`, no floating point.

### Prompt2Mesh — agentic text-to-3D pipeline
**Repo:** https://github.com/vanshika-0305/Prompt2Mesh (co-developed)

- 6-stage pipeline: prompt → scene graph → 3D generation → optimization.
- Groq NLP, FAISS semantic retrieval, Gaussian Splatting reconstruction, Blender MCP post-processing.
- Presented at Sankalp Innovation Challenge 2026.
